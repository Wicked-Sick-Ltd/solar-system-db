solar-system-db

A queryable catalogue of known solar-system objects — planets, moons, dwarf planets, asteroids, comets, TNOs, centaurs, and rings. For astronomy, science education, sci-fi worldbuilding, and model-building. Not astrology.

📡 REST API

Read-only HTTP/JSON. Swagger UI & OpenAPI spec.

🤖 MCP endpoint

Connect AI agents directly (streamable HTTP).

📦 GitHub repo

Source, schema, populate scripts. Clone & run locally.

📊 Stats

Total counts, last refresh timestamp.

Quick examples

curl /api/v1/planets/Saturn/moons
curl /api/v1/objects/1P/Halley
curl '/api/v1/positions/Earth?date=2030-01-01'
curl '/api/v1/search?q=Halley'
curl '/api/v1/close-approaches?from=2029-01-01&to=2029-12-31&max_dist_au=0.01'
curl '/api/v1/sky/Jupiter?lat=51.5&lon=-0.12'
curl /api/v1/download

Data sources

Everything is sourced from public-domain catalogues:

  • NASA JPL Solar System Dynamics — planets, moons, fact sheets
  • JPL Small-Body Database — asteroids, comets, TNOs
  • IAU Minor Planet Center — named-asteroid & periodic-comet lists
  • NASA Planetary Fact Sheets — physical properties

Refreshed nightly from upstream. Schema, source, and licence info: see the GitHub repo.

solar-system-db is MIT-licensed. Upstream data is NASA public-domain plus freely-redistributable IAU MPC. No tracking, no analytics, no auth — public and read-only by design.
